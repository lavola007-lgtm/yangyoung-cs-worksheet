# 양영학원 선생님 실습지

양영학원 전 관 선생님 대상 CS 교육(120분)에서 쓰는 실습용 웹앱입니다.

- 공개 주소: https://lavola007-lgtm.github.io/yangyoung-cs-worksheet/ (GitHub Pages)
- 구성: 시작 · 실습 1~4 · 도구함(처방 세 줄, 응대 네 칸, 결석 3색, 인계 한 장, 90일 달력, 상담 언어) · 내 기록
- 정적 사이트(HTML/CSS/JS). 서버·저장소 없음. 입력 내용은 브라우저 화면에만 있고 전송·저장되지 않습니다. 내 기록에서 .txt로 받거나 복사합니다.
- 실습에는 아이·학부모 실명을 적지 않습니다.

로컬 실행: `index.html`을 브라우저로 열거나 `python3 -m http.server`로 띄웁니다.
